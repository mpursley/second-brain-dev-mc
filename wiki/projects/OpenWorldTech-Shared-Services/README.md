# OWT Shared Services

This repository/directory contains shared services for the OpenWorldTech (OWT) umbrella.

## Services
- **Global Whitelist:** Centralized access control for all OWT sites.
- **Global Waiting List:** Centralized registration for early access across all OWT sites.

## Tech Stack
- Node.js (Express)
- SQLite (Local) / Firestore (Production)
- Firebase Auth (for Google ID verification)
