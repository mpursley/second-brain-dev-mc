# Task List Key

This project tracks the implementation and validation of standard features across all active sites under the OpenWorldTech (OWT) umbrella.

## Standard Requirements
- **Landing Page:** A functional, visually appealing homepage.
- **Contact Page:** A form that sends messages to `contact@domain`.
- **Waiting List:** (Optional) A request form for early access/notifications.
- **Whitelist:** (Optional) Google Account-based access control.
