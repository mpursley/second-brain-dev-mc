# OpenWorldTech Projects

Open Intelligence. Open Tech. Open World.

This repository serves as the central hub for tracking projects, documentation, and operational tasks for **OpenWorldTech Inc.**

## Our Mission

OpenWorldTech is building a dual-pronged AI ecosystem designed to solve the complexity of modern life and enterprise infrastructure. We engineer intelligent products that harness dynamic context and deep data to drive measurable impact.

## The Ecosystem

- **The Genius Suite (B2B):** Cloud-native solutions, unified observability, and AI/LLM safety red-teaming for enterprises.
- **The Assistant, PhD (B2C):** An "SRE for Your Life" autonomous intelligence platform for personal habits, wellness, and workflows.
- **The Creative Suite (B2C):** High-utility media tools (Touch Up My Photo/Video/etc.) that serve as top-of-funnel magnets.

## Project Structure

- `docs/`: Centralized resources, shared **company-docs** (cap tables, strategy, etc.), domain lists, and architectural documentation.
- `projects/`: Task lists, job descriptions (JD), the **pitch-deck** presentation, [provisional tasks](./projects/provisional-tasks.md), and specific project tracking (e.g., Site Foundation).
